## Legend

Ports are referenced as `P1/<port>` and `P2/<port>`.

| Label | Meaning |
| --- | --- |
| `HK` | basement drops |
| `WZ-TV` / `WZ TV` | living room TV outlets |
| `2OGSüd` | second floor, south side |
| `2 OG P<n>` | second floor outlets |
| `Lena` | Lena's room |
| `?` | patched, far end unknown |
| `empty` | not patched |

PoE: `-`, `PoE` (af, 15 W), `PoE+` (at, 30 W), `PoE++` (bt, 60/90 W).
Speed: `1G` unless noted, otherwise `2.5G`, `5G`, `10G`.
